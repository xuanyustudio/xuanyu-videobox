# 视频加字幕

## 目标

在桌面端左侧导航增加「加字幕」页，放在「音频分离」和「设置」之间。用户可以选择一个或多个视频，也可以选择零个、一个或多个字幕文件。字幕按主文件名配对；对不上的视频用「设置」里现有的语音识别生成字幕，再烧进画面。页面可以设置字幕样式。成片和识别出的字幕都写在对应视频旁边，不覆盖原片。

## 不在本次范围

- 不做预览。
- 不修改「一键原创」的界面和行为。
- 不把任务写入工程。
- 不扫描视频所在目录里未选中的字幕。只有本次「选择字幕」选中的文件参与配对。
- 不把 SRT、ASS、SSA、VTT 互相转换。选中的字幕原样交给 ffmpeg 的 `subtitles` 滤镜。

## 页面

入口在 `app.go` 的左侧导航。图标用 `theme.FileIcon()`。页面文件为 `internal/ui/page_subtitle.go`，构建标签与其它页面一样是 `fyne_gui`。

控件：

- 「选择视频」：调用现有 `pickVideoFiles`。对话框本身支持选一个或一次选多个。再次选择替换上一次的视频列表。
- 「选择字幕」：调用现有 `pickSubtitleFiles`。可以不选。再次选择替换上一次的字幕列表。
- 「清除字幕」：清空字幕列表。
- 样式：字号 10–72、字体、主色、描边色、描边 0–8、阴影 0–8、距底部 0–200。字体选项为 Arial、Microsoft YaHei、SimHei、SimSun。颜色是文本框，格式 `#RRGGBB`。
- 「开始」「停止」「打开所在文件夹」。
- 两行说明：已选视频、已选字幕。未选择时分别显示「未选择视频」和「未选择字幕」。选中 1 个时显示完整路径；多于 1 个时显示数量。

默认样式与 `original.DefaultSubtitleStyle` 相同：字号 22、Arial、主色 `#FFFFFF`、描边色 `#000000`、描边 2、阴影 1、距底部 36。

处理过程中禁用选择和开始，启用停止。空闲时停止不可用。还没有成功成片时，「打开所在文件夹」不可用；有成片后打开最后一条成功成片所在的目录。

## 配对

纯函数放在 `internal/subtitleburn`。

```text
Pair(videos, subtitles []string) (items []Item, unused []string)
```

`Item` 包含视频路径和字幕路径。字幕路径为空表示这条要先识别。

配对键是文件名去掉扩展名后，用 `strings.ToLower` 得到的字符串。`A.MP4` 与 `a.srt` 是同一个键。路径目录不参与比较。

同一键有多份字幕时，扩展名优先级为 srt、ass、ssa、vtt，其余扩展名排在后面。优先级相同则保留用户选择列表里更靠前的那份。落选的字幕进入 `unused`。

视频按选择顺序输出。同一个键出现多个视频时，第一支视频拿走该键选中的字幕，后面的视频字幕路径为空，走识别。

没有选中字幕时，每支视频的字幕路径都为空，`unused` 为空。

字幕选中了但没有任何视频用到它时，它留在 `unused`。开始处理前弹出说明，列出这些文件名。用户关闭说明后开始处理。这个说明不提供取消，也不阻止处理。

## 输出路径

成片与视频在同一目录，文件名为 `原名_sub.mp4`。识别字幕为 `原名_asr.srt`。目标已存在时，在扩展名前追加 `_2`、`_3`……，从 2 起找第一个不存在的路径。不使用 `_1`。原片路径永远不是输出路径。

例：目录里已有 `clip_sub.mp4` 和 `clip_sub_2.mp4` 时，新成片是 `clip_sub_3.mp4`。

## 处理

按 `Pair` 的顺序逐条处理。状态显示当前序号和文件名，并区分「正在识别」和「正在烧录」。

需要识别的条目使用当前配置里的语音识别，字段与素材页相同：`backend`、`api_url`、`firered_api_url`、`api_key`、`hotword`、`enable_spk`。至少有一条需要识别时，先调用一次 `asr.RequireReady`。未就绪时，这些待识别条目各自记失败并带上该错误，已配对的条目仍烧录。识别调用 `asr.Transcribe`，结果写入上面的 `原名_asr.srt`（含重名递增）。识别返回错误时，该条失败，不烧录。

烧录命令：

```text
ffmpeg -y -i <视频> -vf subtitles='<转义路径>':force_style='<样式>' -c:v libx264 -preset ultrafast -crf 23 -pix_fmt yuv420p -c:a copy -movflags +faststart <成片>
```

工作目录是视频所在目录。字幕路径的转义与现有 `media.escapeSubtitlesFilterPath` 相同：能写成相对视频目录的相对路径时用相对路径，冒号和单引号按该函数的规则转义。

`force_style` 字段和取值范围与现有 `buildForceStyle` 相同：`FontSize`、`FontName`、`PrimaryColour`、`OutlineColour`、`Outline`、`Shadow`、`MarginV`。字体名里的单引号按该函数替换成 `\'`。颜色经现有 `hexToAssBGR` 转成 ASS 的 BGR。不是 6 位十六进制时，该颜色变成 `&H00FFFFFF`。字号限制在 10–72，描边和阴影限制在 0–8，距底部限制在 0–200。距底部为 0 时写入 `MarginV=0`。现有 `buildForceStyle` 会把小于等于 0 的距底部改成 36，新功能不沿用这一处，避免滑块拖到 0 时贴不住底。

一条失败后继续下一条。已成功的成片保留。识别已写出的字幕在烧录失败后也保留。

## 失败与停止

- 没选视频：对话框提示「请先选择要加字幕的视频」，不开始。
- 找不到 ffmpeg：提示到「设置」里配置路径，文案与音频分离页相同，不开始。
- 某一条识别或烧录失败：继续后面的条目。
- 全部成功且只有 1 条：状态为「已保存 」加成片路径。
- 全部成功且多于 1 条：状态为「已保存 N 个，最后一个：」加成片路径。
- 有失败：状态为「成功 N 个，失败 M 个：」加第一条失败的错误原文。N 为 0 时也用这句。
- 点停止：取消当前烧录。识别请求目前没有 context，停止在当前这条识别返回后生效，不再开始下一条，也不再烧录这条。已完成的成片保留。状态为「已停止，已完成 N 个」。N 只计已经成功写出的成片。

## 代码位置

- `internal/subtitleburn`：`Pair`、唯一输出路径、样式字符串、烧录。烧录接受 `context.Context`，以便停止。
- `internal/ui/page_subtitle.go`：选文件、样式控件、进度和状态。
- `internal/ui/app.go`：注册导航项。
- 导出或复用路径转义，供烧录使用。不改 `media.BurnSubtitles` 现有调用方的行为。

## 测试

单元测试不启动 ffmpeg，也不连接识别服务。

- 配对：大小写、扩展名优先级、同扩展名时选择顺序靠前者胜出、同名多视频只有第一支拿到字幕、未使用字幕、空字幕列表。
- 输出路径：目标不存在时用基本名；已存在时用 `_2`；`_2` 也存在时用 `_3`。
- 样式字符串：默认值、距底部 0 保持 0、非法颜色变成 `&H00FFFFFF`、`#RRGGBB` 转成 ASS BGR。
