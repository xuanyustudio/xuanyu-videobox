# 成片合成与本地配音

本文说明玄宇视频工具箱里，短剧解说的语音识别、成片合成，以及本机配音服务的用法。

## 短剧解说：语音识别

识别台词时，会先从视频抽出音频，再交给本机 FunASR（SenseVoice）。

- 地址为 `http://127.0.0.1:7860`，请保持这个端口，也不要把其他服务占用 7860。
- 对应配置项是 `asr.api_url`。请先在本机启动 FunASR，再做转写。

## 成片合成

在工程的「合成」页可以：

- 选择配音引擎：Edge TTS、MiniMax、Kokoro、OpenVoice、IndexTTS-2
- 预听当前音色（见下方「预听」）
- 调节语速、音量、音调
- 配置 BGM 或 AI 音效（Sonilo）
- 分别调节原声与配音音量
- 打开或关闭字幕，并设置字幕样式
- 选择画面比例和清晰度
- 取消正在进行的合成任务，或打开已生成的成片
- 使用原字幕遮罩，盖住画面上的旧字幕

开裁之前，会先核对全部脚本时间轴与对应片源时长。若有条目的起点或终点超出片源，会一次性用中文列出所有超范围的条目（含序号、时间范围和片源时长），并在裁剪前停止，避免再写出没有画面和声音的空文件。

## 预听

预听使用本机 **ffplay** 内置播放，参数为 `-nodisp -autoexit -loglevel quiet`，不会弹出第三方播放器窗口。

- 开始新的预听会先停止上一段；播放中再点一次即可停止。离开合成页也会停止。
- 请把 `ffplay.exe` 放到与 `ffmpeg.exe` 同一目录，或加入系统 PATH。找不到时会给出中文提示，不会改用外部播放器。
- 「打开成片」仍使用系统播放器，因为那是视频。

IndexTTS-2 的官方示例和已选的克隆参考音频，预听时直接播放本地文件，不必启动配音服务，也不会走合成。

## 本地配音服务

下列服务都只监听本机。请先启动对应脚本，再在合成页选择该引擎做**正式合成**。

### Kokoro

- 启动：双击 `E:\kokoro-tts\启动Kokoro.bat`
- 地址：`http://127.0.0.1:3211`
- 设置项：`tts.kokoro_url`

### OpenVoice

- 启动：双击 `E:\OpenVoice\启动配音服务.bat`
- 地址：`http://127.0.0.1:3212`
- 设置项：`tts.openvoice_url`、`tts.openvoice_reference`
- 不要占用 `7860`，该端口留给 FunASR。
- `启动音色克隆.bat` 会打开 Gradio 界面，可能与其他服务抢端口。日常配音请用「启动配音服务.bat」。

### IndexTTS-2（官方 2，不是 2.5）

- 启动：双击 `E:\indextts2\启动IndexTTS2.bat`
- 地址：`http://127.0.0.1:3213`
- 设置项：`tts.indextts2_url`（默认即上述地址）、`tts.indextts2_reference`
- 第一次加载模型可能要几分钟。
- 启动脚本必须直接调用 `E:\indextts2\.venv\Scripts\python.exe`，不要使用 `uv run`（会尝试联网，失败后服务起不来）。
- 下拉中有官方示例 01 到 09、11、12（官方包没有 10）。预听这些示例会直接播放 `E:\indextts2\examples\voice_XX.wav`，不必启动服务。
- 「克隆音色」需要先选择一段参考 wav/mp3；预听已选参考音频时同样不调用合成。没选参考音频会提示，不会卡住。
- 正式合成（官方示例或克隆）仍需先启动服务。

## 音色推荐等级

下拉里会对比较适合「电影解说 / 短剧解说」的音色做标记，推荐的排在前面：

- ★★★ 推荐
- ★★ 常用
- 未标记：不太适合解说，或属于自定义克隆

Edge TTS 和 MiniMax 的系统音色已按上述规则标记。IndexTTS-2 官方示例如下：

| 音色 | 等级 | 说明 |
|------|------|------|
| 官方示例 05 | ★★★ 推荐 | 男声沉稳，接近纪录片旁白，最适合解说 |
| 官方示例 03 | ★★ 常用 | 普通话女声口播，可作旁白备选 |
| 官方示例 04 | ★★ 常用 | 较沉稳女声，可作旁白备选 |
| 官方示例 06 | ★★ 常用 | 普通话讲述腔，可作旁白常用 |
| 官方示例 01、02、07、08、09、11、12 | 不评级 | 英语、过短、情绪对白或语气不太适合中文解说 |
| 克隆音色 | 不评级 | 使用你自己的参考音频 |

## 配置文件

本机配置在：

`C:\Users\admin\AppData\Roaming\narrato-go\config.yaml`

也就是 `%AppData%\narrato-go\config.yaml`。该文件已被 git 忽略，请不要把真实的 API 密钥写进仓库或文档。

与配音相关的配置项：

- `tts.engine`：`edge` / `minimax` / `kokoro` / `openvoice` / `indextts2`
- `tts.kokoro_url`：默认 `http://127.0.0.1:3211`
- `tts.openvoice_url`：默认 `http://127.0.0.1:3212`
- `tts.openvoice_reference`：OpenVoice 参考音频（可选）
- `tts.indextts2_url`：默认 `http://127.0.0.1:3213`
- `tts.indextts2_reference`：IndexTTS-2 克隆用的参考音频

语音识别：`asr.api_url`，默认 `http://127.0.0.1:7860`。

## 构建编号版本

日常请把新包打成带时间编号的文件，避免覆盖正在运行或被占用的 `dist\玄宇视频工具箱.exe`。例如：

```powershell
cd E:\NarratoAI\narrato-go
$env:Path = "$PWD\tools\w64devkit\bin;$env:Path"
$env:CGO_ENABLED = "1"
$stamp = Get-Date -Format "HHmm"
go build -tags fyne_gui -ldflags "-H windowsgui -s -w" -o "dist\玄宇视频工具箱-$stamp.exe" .\cmd\narrato
```

`scripts\build_windows.ps1` 会写入 `dist\玄宇视频工具箱.exe`。若该文件已打开或被锁定，不要强行覆盖，改用上面的编号文件名即可。

`dist/` 已在 `.gitignore` 中，编号 exe 不必提交进仓库。分发前请把 `ffmpeg.exe`、`ffprobe.exe`、`ffplay.exe` 放到与 exe 同一目录（或确保已在系统 PATH 中）。
